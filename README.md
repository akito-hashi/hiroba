# 広場

友達とブラウザで遊べるゲーム集です。シックスボールパズル・ヨット・ヒットアンドブロー・ルドー・トイベースボールの5つを、
ひとりで（CPU 対戦）か、最大12人が集まれる「広場」で友達と遊べます。友達は招待 URL を開くだけで参加できます。

個人が趣味で作った作品です。

# シックスボールパズル

## 遊び方

- 3つ一組のボールが落ちてきます。色は6種類（赤チェック・青マーブル・オレンジ縞・緑格子・紫W・黄）。同じ色を **6つ繋げる** と消えます。
- おじゃまが崩れて偶然6つ繋がったときも、その場で消えて自分の攻撃になります。
- 次の形で消すと「役」になり、盤上のその色が全部消えて、相手の陣地に **役の形をしたおじゃまの塊** が降ります。
  - **ストレート**（6つ一直線）: 横一列の塊 ×2
  - **ピラミッド**（3・2・1 の三角形）: ピラミッドの塊 ×4
  - **ヘキサゴン**（6つで輪）: 六角形（輪＋中心の7個）の塊 ×3
  - 役なしの6つ消し: 単体ボール 3 個（6を超えた1個ごとに +1）
- おじゃまの塊は色がバラバラで、着地すると崩れます。普通のボールとして消せます。
- 予告から2手後に降ってきます。自分が送る塊1つで、予告の塊を1つ打ち消せます。
- 盤面は横10列×縦16段。ピンクの点線より上に残ったら負け。3本先取です。

| キー | 操作 |
|---|---|
| ← → | 移動 |
| ↑ | 即落とし |
| ↓ | 速く落とす |
| Z / X | 回転 |

## モード

- **ひとりで練習**
- **CPU 対戦**（よわい / ふつう / つよい）
- **ネット対戦**: 「部屋を作る」で出る URL を友達に送り、相手が開くと対戦開始。
  ブラウザ同士を直接つなぐ（WebRTC / PeerJS の無料公開サーバーで接続を仲介）ため、
  学校や会社などのネットワークではつながらないことがあります。

# ヒットアンドブロー

数当て（色当て）ゲームです。トップ画面の「ひとりで遊ぶ」（CPU 対戦）か、「友達と遊ぶ」の部屋から選びます。

- お互いに、6色から4つ並べた「正解」を決めます。**同じ色を何度使ってもかまいません**（1296通り）。
- 交互に相手の正解を推測し、ヒット（色も位置も一致）とブロー（色だけ一致）の数が返ります。
  同じ色が重なるときは、ヒットに使った玉をブローに二重に数えません。
- 相手の正解を完全に当てた方の勝ち。先攻が当てても、後攻には同じターンの最終チャンスがあり、
  両方当てたら引き分けです。10ターンずつで決着しなければ引き分け。
- 部屋の作り方・つながりにくい環境はシックスボールパズルのネット対戦と同じです。

正解は自分のブラウザだけが持ち、相手の推測は自分のブラウザで判定して返します。
試合の最初に正解の「封印値」（ハッシュ）だけを交換し、決着後に正解を公開して照合するので、
相手の正解を覗くことも、嘘の判定を返すこともできません（嘘は決着後に「不正」として負けになります）。

## 開発

```bash
npm install
npm run dev     # http://localhost:5173 で起動
npm test        # テスト
npm run build   # dist/ に出力
```

## 公開（GitHub Pages）

1. GitHub にリポジトリを作って push する（ブランチ名 `main`）。
2. リポジトリの Settings → Pages → Source を **GitHub Actions** にする。
3. 以後 `main` に push するたびに、テスト → ビルド → 公開が自動で行われます。
